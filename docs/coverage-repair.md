# 退勤後の不足補正（ローカル実装）

既存の生成・最低勤務時間延長・担当変更の後に、日ごとの残存不足を確認する。30分ずつ進めた際に見逃した不足に対し、必要なら開始時刻を戻して連続勤務を追加する。通常の候補者選択そのものを先読み探索へ置換する変更ではない。

希望・時間帯休み・担当資格を守り、新人は補正対象外。既存勤務を削除・移動せず、最低時間と連続勤務を満たす追加区間を列挙する。アルバイトを社員より優先し、余剰時間が少ない案、追加時間が少ない案、従業員ID、開始時刻の順で選ぶ。社員は代替がなければ既存勤務から連続延長できる。希望時間が最低勤務時間未満の場合は既存ロジックの短時間希望例外を維持する。

不足の判定は設定されたポジション別必要人数。経験レベル条件だけの不足はこの追加処理の対象外。全期間の最適解は保証しない。補正の追加行は一括トランザクションで保存し、失敗時は追加行のみロールバックする。

検証: Java 17向けコンパイル、既存76項目と追加13項目、計89項目通過。追加検証は架空データで、18:30不足への18-22配置、代替不在時の社員延長、休み・担当資格・新人制約・短時間希望・重複防止を確認。実DBへの新SQL実行、本番反映、実シフトの再生成は未実施。
