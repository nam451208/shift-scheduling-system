# README用スクリーンショット

追加画像 `shift-results-redacted.png` と `shortage-redacted.png` は、2026年9月29日に本番から取得したHTMLの氏名・ログイン名を仮名に置き換えてChromeで撮影しました。シフト画像は10月9日の部分を掲載し、勤務時間・不足人数は変更していません。撮影用HTMLは一時ディレクトリのみ保存し、認証情報・Cookieは画像やリポジトリに保存していません。

新しい画像はこのフォルダーへ保存し、ルートのREADME.mdの「画面紹介」にMarkdownの画像リンクを追加すると掲載できます。

| ファイル名 | 撮影する画面 | 見せたいポイント |
| --- | --- | --- |
| request-form.png | 希望入力 | 開始日・終了日、休み・終日OK・時間指定、合計時間 |
| shift-results.png | シフト結果 | 生成された時間帯ごとの配置 |
| statistics.png | 集計 | 希望時間と採用時間、出勤回数の比較 |

## 撮影の手順

1. 掲載用のダミー名・サンプルデータを使った画面を開きます。
2. ブラウザの幅をそろえ、見せたい内容が読める倍率にします。
3. Windowsの `Win + Shift + S` で必要な部分を撮影します。
4. ログイン名や実在する従業員の名前が写っていないか確認します。
5. 上記のファイル名でPNG形式で保存します。
6. READMEの画像用コメントを外し、VS CodeのMarkdownプレビュー（Ctrl + Shift + V）で確認します。

希望入力は日付の変更欄がある最新版を撮影してください。画像だけでなく、画像の直前に画面名、直後に操作や読み取り方を短く添えると伝わりやすくなります。
